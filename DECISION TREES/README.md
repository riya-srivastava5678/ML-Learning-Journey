## 🧠 How Decision Tree Works

A Decision Tree recursively splits the dataset based on feature conditions to create groups that are as pure as possible.

For classification, common splitting criteria include:

* **Gini Impurity**
* **Entropy / Information Gain**

For regression, the tree commonly uses measures based on the prediction error within each split.

## 📈 Key Learning

Decision Trees are easy to understand and interpret, but they can easily **overfit** the training data. Hyperparameters such as `max_depth`, `min_samples_split`, and `min_samples_leaf` can be used to control the complexity of the tree.
