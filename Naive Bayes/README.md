# Naive Bayes

Implementation of the **Naive Bayes Classification Algorithm** using Python and Scikit-learn.

## 📌 Project Overview

In this project, I implemented Naive Bayes on a **Loan Approval dataset** to understand how probabilistic classification works.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## 📂 Files

- `naivebayesimplement.ipynb` – Naive Bayes implementation
- `loan_data.csv` – Dataset used for training and testing

## 🧠 Algorithm

**Naive Bayes Classifier**

It is a probabilistic classification algorithm based on **Bayes' Theorem**.

## 🎯 Key Learnings

- Bayes' Theorem
- Naive Bayes classification
- Data preprocessing
- Model training and prediction
- Model evaluation
